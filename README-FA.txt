AFG AI — پروژه اندروید برای ساخت APK

این پروژه رابط فعلی AFG AI را داخل یک برنامه Android WebView قرار می‌دهد. فایل APK در این بسته نیست؛ GitHub Actions آن را برایت می‌سازد.

روش ساخت APK با گوشی:
1) یک مخزن GitHub بساز (مثلاً AFG-AI-Android).
2) همه فایل‌های این پوشه را در ریشه مخزن آپلود کن؛ پوشه .github را هم حتماً نگه دار.
3) در GitHub مخزن را باز کن و به زبانه Actions برو.
4) اگر خواست، گزینه I understand my workflows, go ahead and enable them را بزن.
5) workflow به نام Build AFG AI APK را انتخاب کن و Run workflow را بزن. اگر بعد از آپلود فایل‌ها خودکار اجرا شده، همان اجرا را باز کن.
6) وقتی وضعیت سبز شد، پایین صفحه در بخش Artifacts روی AFG-AI-APK بزن و ZIP دانلودشده را استخراج کن.
7) داخلش app-debug.apk است. آن را به گوشی دانلود و باز کن؛ اگر اندروید اجازه خواست، نصب از این منبع را مجاز کن.

نکته‌های مهم:
- این فایل، APK آزمایشی (debug) است؛ برای انتشار عمومی باید release را با کلید امضای امن ساخت.
- رابط برنامه داخل APK است، اما پاسخ واقعی AI نیاز به سرور AFG AI آنلاین دارد. در تنظیمات برنامه، نشانی HTTPS سرور را وارد کن.
- چون برنامه به سرور جداگانه وصل می‌شود، سرور باید CORS را برای origin برابر https://appassets.androidplatform.net مجاز کند؛ در غیر این صورت درخواست چت ممکن است مسدود شود.
- کلید API را داخل HTML یا APK قرار نده؛ فقط در متغیرهای محیطی سرور نگهداری کن.
- این پروژه هنوز در این محیط کامپایل/تست نشده است؛ GitHub Actions خروجی APK را می‌سازد و خطاهای احتمالی build را نشان می‌دهد.


اتصال Cloudflare Workers AI:
- در متغیرهای محیطی سرور مقدار CLOUDFLARE_ACCOUNT_ID و CLOUDFLARE_API_TOKEN را تنظیم کن.
- توکن باید دسترسی Workers AI Read و Workers AI Edit/Write داشته باشد تا فهرست مدل‌ها و اجرای مدل‌ها مجاز باشد.
- در صورت نیاز، CLOUDFLARE_AI_MODELS را با شناسه‌های مدل جداشده با کاما تنظیم کن؛ فهرست پویا از API حساب Cloudflare خوانده می‌شود.
- مدل‌ها فقط پس از دریافت موفق فهرست مدل‌های text-generation وارد فهرست می‌شوند؛ اگر شناسایی مدل شکست بخورد، Cloudflare به‌عنوان مدل آماده نمایش داده نمی‌شود.
- کلید API و Account ID فقط در تنظیمات محیطی سرور نگهداری شوند، نه در APK یا رابط کاربری.
